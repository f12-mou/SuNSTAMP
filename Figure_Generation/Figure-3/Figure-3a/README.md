# Top 10 Genes Bar Plot (H Matrix, 13 months AD)

## Overview
This script generates a bar plot of the **top 10 genes** from the H matrix (13 months AD).  

## Files
- `H_genes.csv` – Input file containing two columns: `Gene`, `Value`.  
- `Figure-3a.py` – Script for generating the bar plot.  
- `Figure-3a.png` – Output figure produced by the script.
