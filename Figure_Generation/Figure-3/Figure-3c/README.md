# Venn Diagram: Overlap of Top 20 Genes (13 months AD mouse brain)

## Overview
This folder contains a Venn diagram illustrating the overlap of **top 20 genes** identified by SuNSTAMP from two replicates of the 13 months old AD dataset:

- Replicate 1  
- Replicate 2  

## Files
- `Figure-3c.png` – Venn diagram showing the overlap of top 20 genes between replicate 1 and replicate 2.  

## Source of Gene Lists
The lists of top genes used to generate this figure can be found in the results folders of each replicate analysis:

- `SuNSTAMP/SuNSTAMP-AD/replicate_13_1/result/`  
- `SuNSTAMP/SuNSTAMP-AD/replicate_13_2/result/`
