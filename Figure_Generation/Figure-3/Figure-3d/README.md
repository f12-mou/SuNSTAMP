# AUC-ROC Cross-Validation Between AD Replicates  

This folder contains the results of an analysis comparing two replicates of **13-month-old AD mouse brain** samples. The comparison is based on **cross-validation performance**, evaluated using the **AUC-ROC score**.  


## Data & Results  
To reproduce or inspect the analysis, please refer to the following files in this directory:  

1. `SuNSTAMP/SuNSTAMP-AD/replicate_13_1/result/`  
2. `SuNSTAMP/SuNSTAMP-AD/replicate_13_2/result/`  

These files contain the processed data/results used to generate the AUC-ROC figure.
