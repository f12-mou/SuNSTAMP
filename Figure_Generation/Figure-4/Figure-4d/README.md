# Top 10 Genes Bar Plot (H Matrix, 7 Days Post-MI)

## Overview
This script generates a bar plot of the **top 10 genes** from the H matrix (7 days post-myocardial infarction).  

## Files
- `H_7_2.csv` – Input file containing two columns: `Gene`, `Value`.  
- `Figure-4d.py` – Script for generating the bar plot.  
- `Figure-4d.png` – Output figure produced by the script.
