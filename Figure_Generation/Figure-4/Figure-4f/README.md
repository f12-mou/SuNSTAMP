# Venn Diagram: Overlap of Top Genes (MI, 7 Days Post-MI)

## Overview
This folder contains a Venn diagram illustrating the overlap of **top genes** identified by SuNSTAMP from two replicates of the myocardial infarction (MI) dataset, 7 days post-MI:

- Replicate 2  
- Replicate 3  

## Files
- `Figure-4f.png` – Venn diagram showing the overlap of top genes between replicate 2 and replicate 3.  

## Source of Gene Lists
The lists of top genes used to generate this figure can be found in the results folders of each replicate analysis:

- `SuNSTAMP/SuNSTAMP-MI/replicate_7_2/result/`  
- `SuNSTAMP/SuNSTAMP-MI/replicate_7_3/result/`
