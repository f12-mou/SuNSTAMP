# Venn Diagram: Overlap of Top Genes (MI, 3 Days Post-MI)

## Overview
This folder contains a Venn diagram illustrating the overlap of **top genes** identified by SuNSTAMP from two replicates of the myocardial infarction (MI) dataset, 3 days post-MI:

- Replicate 1  
- Replicate 3  

## Files
- `Figure-4e.png` – Venn diagram showing the overlap of top genes between replicate 1 and replicate 3.  

## Source of Gene Lists
The lists of top genes used to generate this figure can be found in the results folders of each replicate analysis:

- `SuNSTAMP/SuNSTAMP-MI/replicate_3_1/result/`  
- `SuNSTAMP/SuNSTAMP-MI/replicate_3_3/result/`
