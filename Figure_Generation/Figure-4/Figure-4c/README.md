# Top 10 Genes Bar Plot (H Matrix, 3 Days Post-MI)

## Overview
This script generates a bar plot of the **top 10 genes** from the H matrix (3 days post-myocardial infarction).  

## Files
- `H_3_1.csv` – Input file containing two columns: `Gene`, `Value`.  
- `Figure-4c.py` – Script for generating the bar plot.  
- `Figure-4c.png` – Output figure produced by the script.
