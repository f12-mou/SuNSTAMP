# Expression Subplots (AD vs Wild-Type, 3, 6, 12 and 18 Months)

## Overview
This folder contains 8 subplots showing the expression pattern of the **Cst3**, **Ctsb**, **Apoe**, **Gfap**,  gene across Alzheimer’s Disease (AD) and wild-type mouse brains.  

- **Rows:**  
  - Top row – Wild-type mouse brain  
  - Bottom row – AD mouse brain  

- **Columns:**  
  - Four developmental time points: **3, 6, 12, and 18 months**  

## Source
The plots were obtained from [AlzMAP](https://alzmap.org), an online atlas for spatial and temporal gene expression in Alzheimer’s disease mouse models.  

## Citation
If you use these plots, please cite the original publication that describes AlzMAP:  

> Wei-Ting Chen, Ashley Lu, Katleen Craessaerts, *et al.*  
> *Spatial transcriptomics and in situ sequencing to study Alzheimer’s disease.*  
> *Cell*, 182(4):976–991, 2020.
